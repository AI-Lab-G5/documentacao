# Índice de Registos de Decisão de Arquitetura (ADR)

| Número | Título | Status | Resumo (Para o PO) |
| :--- | :--- | :--- | :--- |
| ADR-001 | Stack principal | Proposto | Usaremos Python na nuvem para cálculos matemáticos precisos sem perda financeira ou erro técnico. |
| ADR-002 | Autenticação e autorização | Proposto | Segurança assente em convites restritos, protegendo os dados corporativos sem gastar o orçamento. |
| ADR-003 | Persistência | Proposto | Usaremos a base gratuita da Google, gravando dados como texto inalterável para garantir auditoria. |
| ADR-004 | Estratégia de testes | Proposto | Testes automatizados focar-se-ão em provar que cálculos passados produzem sempre o mesmo resultado. |
| ADR-005 | Versionamento imutável de fatores | Proposto | Nenhum número de fator ambiental será apagado; versões erradas viram obsoletas e novos números são emitidos. |
| ADR-006 | Idempotência e identificação | Proposto | Se houver erro de rede, envios duplos não geram poluição ou duplicam resultados da empresa. |
| ADR-007 | Aritmética decimal | Proposto | Eliminação de erros de arredondamento em cadeia, com totais perfeitamente alinhados à soma das partes. |
